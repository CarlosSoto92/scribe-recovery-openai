# Instrucciones para agentes (Codex, Antigravity y otros)

- Lee `README.md` y `docs/DECISIONS.md` antes de empezar.
- Trabaja en una rama `feat/<tema>` y abre un pull request; no hagas push directo a `main`.
- Cambios chicos y frecuentes, con un commit por idea.
- No subas secretos: usa `.env` local y documenta las variables en `.env.example`.
- Si cambias el stack o la arquitectura, agrega una fila en `docs/DECISIONS.md`.
